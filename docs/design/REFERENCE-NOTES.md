## Current Tangent UI vs references

Compared against the 26 current-UI screenshots in `D:\TANGENT showcase\Images\*.png` (Nov 6, 2026). These list UI problems only: the screenshots contain personal data, which is deliberately not repeated here. Each line: the problem → the reference pattern that fixes it.

- **Shell (every screen)**: there is no Home/Capture item in the nav; a floating mic FAB sits bottom-right on every page and overlaps rows, toolbars and the Confirm row; the lavender gradient and liquid-glass fade make the chrome louder than the content. → `21st-sidebar-clean` (quiet sidebar with Home first, user + Settings at the bottom); the mic lives in the composer only (`21st-ai-prompt-composer-dark`), with a phone FAB above the bottom nav only on screens with no composer.
- **Today, top**: two stacked inputs ("Type or say anything…" and "Ask Tangent anything…" + library icon) and a 3-page dot slider mixing a must-do count, a "Send to" picker and setup prompts. → one composer with an "Auto ▾" pill (`21st-ai-prompt-composer-dark`), view tabs under it (`21st-segmented-tabs-with-icons`), and one dismissible line for questions/setup (`21st-setup-progress-checklist`, collapsed).
- **Today, inline Grill**: the question card ("Tangent knows enough: 36%", answer pills, Skip / Stop planning) is good in content but nests a bordered card inside a bordered card, and the percentage reads as a score. → one flat card under the composer, chips as SegmentedTabs-style pills, Skip and Stop as quiet text buttons; progress as a thin bar without a percentage.
- **Today, must-dos**: full-width pink-red tinted cards for overdue items, a course tag chip on every row, raw long Canvas titles, "Dismiss" and "Done" as text links. → `amie-today-list` (red dot + date, no tint), `things3-mac-sidebar-areas` (group by project, rows don't repeat it), `cleanTaskTitle()` short titles; actions on hover / swipe.
- **Today, empty state**: "Today's plan 0" is an empty tinted card whose copy uses the word "plan". → `21st-empty-state-all-caught-up` with project wording.
- **Calendar month**: dense truncated rows, many "+N more", a bottom toolbar that mixes view, navigation and filter in one long pill bar. → `fantastical-mac-views` (top toolbar: segmented view switch, Today + arrows, filter separate), `notioncal-calendar-views` (chips with a colored left bar).
